## 🛠 Featured Tool Arsenal

- **Markov Kai'Sa:** Live Lolalytics data scraper & Markov decision chain generator for League of Legends. Calculates mathematical utility score ($U$) rather than raw winrate.
- **Antigravity Suite:** Advanced developer tools for the Google Antigravity ecosystem, including RTL fixing, OpenCode routing, and model injections.
- **Gemini Watermark Cleanser:** Synthetic image watermark removal tool for AI-generated visual media.
- **Universal Skill Converter:** Cross-ecosystem translator for agentic SKILL.md specs.
- **Media Pipeline Bots:** Automated speech and audio synthesis tools for Telegram channels.
- **Domain-Specific Parsers:** Precision tabular OCR/RTL extractors for petroleum payrolls and financial statements.
