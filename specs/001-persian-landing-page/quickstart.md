# راهنمای اعتبارسنجی سریع و اجرای مقایسه‌ای (Quickstart & Validation Guide)

**کد فیچر**: `001-persian-landing-page`  
**تاریخ**: ۲۰۲۶-۰۹-۲۴ (2026-09-24)  

این راهنما روش اجرای سریع، بازبینی محلی و مقایسه همزمان دو نسخه انگلیسی و فارسی وب‌سایت RashAI.dev را توضیح می‌دهد.

---

## ۱. پیش‌نیازها

- پایتون ۳ یا Node.js برای اجرای وب‌سرور محلی سبک، یا حتی باز کردن مستقیم فایل HTML در مرورگر.
- مرورگر وب مدرن (کروم، فایرفاکس، اج، سافاری).

---

## ۲. راه‌اندازی سرور محلی (Local Server)

برای بررسی دقیق رفتار مسیرها و فونت‌ها در شرایط واقعی هاست:

### روش ۱: با استفاده از Python
```powershell
# در ریشه مخزن (G:\rashai-dev) اجرا کنید:
python -m http.server 8080
```

### روش ۲: با استفاده از Node.js / npx
```powershell
npx serve . -p 8080
```

---

## ۳. سناریوهای مقایسه موازی (Side-by-Side Validation)

دو پنجره کنار هم (Split Screen) در مرورگر خود باز کنید:

| پنجره سمت چپ (نسخه اصلی انگلیسی) | پنجره سمت راست (نسخه جدید فارسی) |
| :--- | :--- |
| `http://localhost:8080/` | `http://localhost:8080/fa/` |

---

## ۴. چک‌لیست اعتبارسنجی کیفی (Validation Checklist)

- [ ] **بررسی عدم تغییر نسخه اصلی**:
  - اجرای دستور `git status` در ترمینال باید نشان دهد فایل `index.html` کوچک‌ترین تغییری نکرده است.
- [ ] **لود صحیح فونت وزیرمتن**:
  - در حالت آفلاین، متون فارسی با قلم وزیرمتن رندر شوند و هیچ فونت سیستمی نامتعارفی نمایش داده نشود.
- [ ] **چیدمان راست‌به‌چپ (RTL)**:
  - جهت‌گیری عناصر، تیکر بالا، تیتر هیرو، کارت‌های آمار و کارت‌های ابزار کاملاً از سمت راست آغاز شوند.
- [ ] **کلیک روی دکمه بازگشت به انگلیسی (`EN / English`)**:
  - از صفحه فارسی روی دکمه کلیک کنید؛ باید بلافاصله به آدرس `http://localhost:8080/` بازگردد.
- [ ] **تست کپی نشانی ایمیل**:
  - در پایین صفحه روی دکمه کپی کلیک کنید؛ پیام Toast فارسی `«آدرس ایمیل با موفقیت کپی شد!»` ظاهر شود و ایمیل در کلیپ‌بورد قرار گیرد.
- [ ] **عدم سرریز افقی (Horizontal Scroll)**:
  - پنجره مرورگر را در اندازه گوشی موبایل کوچک کنید؛ هیچ اسکرول افقی نباید ایجاد شود.
